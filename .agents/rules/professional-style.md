# Profesionálny štýl projektu (UI, kód, dokumentácia)

## Zákaz emojis
- V celom projekte (kód, web UI, HTML, CSS, JavaScript, Python, komentáre, dokumentácia, markdown súbory, commit správy) je prísne zakázané používať emojis.
- Emojis pôsobia neprofesionálne v akademickom a priemyselnom kontexte diplomovej práce.
- Pre ikony používaj výhradne čisté, vektorové SVG ikony s `stroke="currentColor"`, farebné stavové štítky (badges) alebo textové označenia.

## Komentáre a dokumentácia
- Dôsledne udržiavaj odborné komentáre ku všetkým funkciám, triedam, výpočtom uhlov a regulačným slučkám.
- Texty v používateľskom rozhraní musia byť odborné, moderné, slovensky spisovné a technicky presné.
